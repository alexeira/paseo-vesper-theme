Vesper brings the minimal, low-contrast look of the Vesper editor theme to Paseo. Vesper Dark pairs near-black greys with a soft peach accent, Vesper Light uses white surfaces with a deeper orange accent that keeps button text readable, and Vesper Light Mono is the same light palette without an accent. The themes color the app, panels, the terminal and the frame of code blocks; syntax token colors still follow the syntax theme chosen in Paseo's appearance settings, and status colors keep Paseo's defaults.
